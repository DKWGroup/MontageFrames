# Panel MontageFrames — etapy 1–2: plan wdrożenia

> **Dla agentów:** wykonuj zadanie po zadaniu (superpowers:executing-plans). Kroki mają pola wyboru `- [ ]`. Commit tylko na prośbę użytkowniczki.

**Cel:** lokalny panel w przeglądarce (`npm run ui`, http://127.0.0.1:3100). Pokazuje klientów i rolki oraz podgląd tym samym `Reel`. Pozwala edytować napisy i grafiki, renderować do `klienci/<klient>/Render/`, wrzucić nagranie i zlecić montaż operatorowi AI (Claude Code bez okna, na koncie albo z kluczem API).

**Architektura:**
- Vite + React w `ui/`, `@remotion/player` z komponentem `src/Reel.tsx` bez kopiowania.
- API to plugin Vite (`ui/server.mjs`) w tym samym procesie. Źródłem prawdy są pliki (`reel.json`, `klienci/*`).
- Zadania (render, montaż, czat) uruchamiają procesy CLI i trzymają log w pamięci. UI odpytuje je co sekundę.

**Stos:** Vite 8, @vitejs/plugin-react 6, @remotion/player 4.0.532 (ta sama wersja co reszta Remotion), Node 22, testy `node --test`.

Spec: `docs/superpowers/specs/2026-10-07-panel-przegladarkowy-design.md`.

## Kontrakt API (wszystkie zmiany wymagają nagłówka `X-Panel: 1`, ochrona przed CSRF)

| Metoda i ścieżka | Wejście | Wynik |
|---|---|---|
| `GET /api/library` | — | `{ clients:[{id, renders:[{file,size,mtime}]}], loose:[…out/], reels:[{name, client, style, seconds}], jobs:{[reel]:status} }` |
| `GET /api/reel/:name` | — | treść `reel.json` |
| `PUT /api/reel/:name` | `ReelData` | `{ok}`; 409, gdy trwa zadanie; kopia w `historia/` co ≥ 5 min |
| `POST /api/job/:name` | `{kind:"render"\|"montage"\|"chat", input?, message?, render?}` | `{ok}`; 409, gdy trwa zadanie tej rolki |
| `GET /api/job/:name?since=N` | — | `{kind, status, lines, next, pct, result}` albo `{status:"idle"}` |
| `DELETE /api/job/:name` | — | zatrzymanie procesu |
| `POST /api/upload?client=&kind=surowe\|przebitki&file=` | strumień pliku | `{path}` (względem repo) |
| `POST /api/client` | `{name}` | `{id}`; tworzy `PREFERENCJE.md`, `surowe pliki/`, `przebitki/`, `Render/` |
| `GET/PUT /api/settings` | `{operator, apiKey, model, renderAfter}` | klucz zamaskowany (`••••abcd`) |
| `GET /api/operator` | — | `{installed, version, loggedIn, authMethod}` z `claude auth status` |
| `GET /api/file?path=` | tylko `klienci/*/Render/*` i `out/*` | plik do pobrania |
| `POST /api/reveal` | `{path}` | `open -R` (macOS) |
