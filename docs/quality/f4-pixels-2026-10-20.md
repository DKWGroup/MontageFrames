# F4 — raster tekstu i dekoracji, 2026-10-20

**Przyrost lokalny: opcjonalne maski pikselowe pojedynczych warstw renderera. Pełny odbiór F4, projekcja twarzy i PTS pozostają otwarte.** [Poprzedni miernik układu](f4-geometry-2026-10-20.md), [punkt wznowienia](next-stage.md).

## Uruchomienie i koszt

```sh
npm run reel:geometry -- nazwa-rolki --frames 0,12,40 --pixels
npm run reel:geometry -- nazwa-rolki --all --pixels
```

Bez `--pixels` zostaje dotychczasowy tańszy skan DOM. Tryb pikselowy dodaje osobny render PNG dla każdego aktywnego ID i klatki, dekodowanie RGBA przez istniejący FFmpeg oraz odczyt alfa. Nie wywołuje LLM, ASR ani opisu publikacji; zużywa CPU i miejsce na snapshot. Wskazane klatki zapisują także `mask-<frame>-<id>.png` do przeglądu. `--all` nie zapisuje sekwencji normalnych klatek ani masek, ale nadal wykonuje renderowanie i zapisuje hashe/obrysy w raporcie. Koszt obliczeń nie jest zerem.

Pozostaje osobne narzędzie CLI; szybki przycisk panelu nie wykonuje potajemnie ciężkiego skanu. Nie zmienia źródła, draftu, historycznych MP4, stylu, napisów, hooka ani checkpointu AI. Infrastruktura Vercel/backend/Supabase nadal odłożona.

## Co mierzymy

- Chromium renderuje kontrolnie przezroczystą warstwę jednego ID: napis, hook albo emotkę. Inne gałęzie pozostają w układzie, lecz ich malowanie jest wyciszone. Emotka i napis mają osobne maski. Zachowane zostają fonty, transforms, skala, obrót, clipping, opacity, tła/marker, stroke, cień i zwykłe filtry CSS. Pseudo-elementy celu pozostają częścią warstwy.
- Kontrola porównuje geometrię i obliczone style celu, także pseudo-elementów, przed i po izolacji. Style i opakowane węzły tekstowe są przywracane przy sprzątaniu. Izolacja działa wyłącznie w renderze kontrolnym, nigdy w zwykłym eksporcie.
- Obrys obejmuje każdy piksel PNG o alfa ≥ 1/255, również słaby cień. Ujemny bearing litery nie zależy już od `Range`/advance. Pomiar ma logiczny kadr 1080×1920 przy skali 1; nie jest odbiorem innych rozdzielczości, 16:9, systemów ani historycznego MP4.
- To obrys **izolowanej warstwy**, zachowujący jej własne i odziedziczone przycięcia. Nie jest segmentacją finalnego obrazu i nie dowodzi, które piksele przykryła inna warstwa. Nadmierny obrys może wymagać przeglądu; nie używać go do automatycznego usuwania tekstu lub zmiany wyglądu.
- Blend/backdrop i animacje zależne od tła/czasu, zmiana stylu/układu przy izolacji, brak ID, niegotowy obraz oraz niepotwierdzona pusta maska pozostają `unknown`. Sprawdzane są także wygenerowane pseudo-elementy. Puste alfa bez dowodu ukrycia nie udaje niewidocznego poprawnego elementu: tekst mógł wypaść za kadr. Maska dotykająca brzegu kadru nie potwierdza pełnego obrysu poza tym kadrem.

## Wiązanie dowodu

Manifest zawiera jawny tryb `raster-v1`, dane i źródło, silnik/zasoby/fonty/runtime. Raport v2 `remotion-raster-v1` zawiera osobne `rasters`: manifestSignature, klatka, ID/rola, metoda `isolated-alpha-v1`, rozmiar rastra, SHA PNG, liczba pikseli, całkowity obrys i status izolacji. Obrysy są normalizowane dopiero z tego rastra.

Walidator wymaga powiązania, wymiarów, poprawnej struktury i zgodności prostokąta z maską dla każdego oczekiwanego ID; brak lub zmiana sygnatury/klatki/maski nie może potwierdzić ani zgłosić definitywnego błędu nowej wersji. Częściowe klatki mogą wykryć problem własnej wersji, ale nie poświadczają całej animacji. Pochodzenie jest gwarantowane wewnątrz lokalnego wykonania skanera, nie podpisem kryptograficznym cudzych edytowalnych JSON. Nie ma publicznego API przyjmującego takie dowody od odbiorców.

`text.face-evidence` nadal ma `unknown`: brak pełnej projekcji twarzy z oryginału do wyjścia. Poprawne maski nie odblokowują samodzielnie akceptacji całej rolki, badge ani publikacji.

## Review i próby

- Niezależny review: 0 Critical, 2 Important, 0 Minor. Odtworzono oba błędy: sąsiedni `display:contents` powiększał maskę 50×50 do 650×650, a zależny od tła pseudo-element omijał guard. Poprawione RED→GREEN. Wyciszanie kontenerów bez własnego pola jest rekurencyjne, a guard i kontrola stylów obejmują pseudo-elementy.
- Raster kontra niezależny przezroczysty obraz odniesienia: Poppins, Nunito, Libre Baskerville, `j`/`f`, polskie znaki, wielowierszowość, flaga, obrót/skala przodka, opacity, cień, stroke, blur, clip-path, zwykły pseudo-element i osobna emotka. Sprawdzane jest także odtworzenie oryginalnego DOM.
- Polityka dowodu: słabe alfa, brzeg rastra, błędny rozmiar PNG, puste/ukryte maski, zła klatka i manifest, brak SHA, niepełny inwentarz, nieobsługiwana izolacja. Testy syntetyczne nie stanowią odbioru korpusu klientów.
- Pierwsze próby podczas wysokiego obciążenia komputera zakończyły się błędem istniejącego preflightu fontów i timeoutem nawigacji Chromium. Nie obniżono walidacji ani nie wydłużono limitów w celu uzyskania PASS; osobna późniejsza kontrola Poppins przez CoreText zwróciła PASS. Końcowe wyniki integracji i suite są zapisywane poniżej po wykonaniu.
