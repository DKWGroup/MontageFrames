# F3 — zwykłe rolki i bezpieczne poprawki lokalne

2026-10-19. Przyrost kontynuuje [odbiór F3 z 18.10](f3-acceptance.md), bez uruchamiania infrastruktury.

## Gotowe w tym przyroście

- Zwykły edytor ma teraz te same jawne zakresy poprawki co QC: pełny montaż, tekst napisów, tekst i istniejący hook. Pełny operator plikowy pozostaje dla kadru, mediów i pozostałych nieobsługiwanych operacji.
- Nowy `editOrdinaryReel` korzysta z dotychczasowego transportu konta i wspólnych schematów v2/v3. Drobna korekta nie wywołuje ingest, ASR ani renderu. Panel korzysta z wybranego konta Claude; terminal może jawnie wskazać Claude albo Codex. Nie uruchamiano w tej sesji rzeczywistej redakcji AI.
- Mały zakres w zwykłym panelu nie przełącza potajemnie wybranego API na konto: konfiguracja API wymaga dotychczasowego pełnego zakresu lub jawnego wyboru konta. Nie dodano płatnego fallbacku.
- Próba i jej usage są zapisane w `.quickcontent/reel-edits/` przed walidacją odpowiedzi, także po błędzie. Błąd albo nieznana opłata nie oznaczają zera. Historia terminala i poprzednie filmy zostają.
- Kontekst v3 jest związany z hashem źródła i rewizją JSON. Ponowna kontrola rewizji i źródła odbywa się pod międzyprocesową blokadą store przed zapisem; nowsza poprawka lub podmieniony film odrzucają odpowiedź AI.
- W zakładce Grafiki istniejący hook ma ręczne pole „Tekst hooka — bez AI”. Zmiana zachowuje czasy, pozycję i wielkość; usuwa nieaktualny fragment wyróżnienia. Pola napisów i kadru pozostają bez AI.

## Terminal

```sh
npm run reel:ops -- nazwa-rolki context
npm run reel:ops -- nazwa-rolki apply operacje.json
npm run reel:ops -- nazwa-rolki edit operations "Popraw literówkę" --provider=codex
npm run reel:ops -- nazwa-rolki edit captions "Połącz słowa w sensowne grupy" --provider=claude
```

Pierwsze dwie komendy są ręczne, bez modelu. `edit` używa wskazanego zalogowanego konta i jego limitów. Rolki QC nadal obsługuje własny worker i lokalny endpoint operacji; ten CLI celowo odmawia ich zapisu, żeby zachować blokady aktywnych jobów. Dotychczasowe CLI QC i pełny montaż działają jak wcześniej.

## Dowody i ograniczenia

RED→GREEN: wspólna redakcja z zachowaniem czasów/kadru/źródła, błędny zakres, trwałe usage przy błędzie i konflikcie, podmienione źródło, CLI konta, brak wywołania dla API/QC w tej ścieżce, unieważnienie opisu v2 oraz ręczny tekst hooka. Niezależny review wykrył podmianę samych bajtów źródła bez zmiany JSON; test odtworzył problem, a sprawdzanie SHA pod blokadą go naprawiło.

Pełny operator kadru/mediów nadal nie jest całkowicie v3; nie migrowano starych szablonów i nie odtwarzano automatycznie masterów przy zmianie klienta. Wykonanie zależności poza tym zakresem i benchmark docelowego API pozostają otwarte. Cena API nie została wywnioskowana z rozmiaru promptu.
